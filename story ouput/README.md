## The five reveal ladders (what "the merges" fixed)
Each reveal escalates one rung at a time; no fact is disclosed twice.
- **A · Killswitch:** fired&failed (Ch2) → sabotaged (Ch4) → internal dissent (Ch7) → leash-tech scaled into the Concord Engine (Ch9) → Heris built both (Ch13).
- **B · Conscience:** mercy operative (Ch1) → first defector (Ch3) → mercy is his own (Ch4) → empathy is the engineered flaw (Ch6).
- **C · Identity:** "Kael Vor" is fake (Ch5) → he's the prime template the editions were cloned from (Ch12) → birth name **Soren** (Ch16).
- **D · Antagonist:** Khall, the Overseer (Ch4) → his recorded grief in the Garden's vision (Ch8) → forged order (a Synod gambit to break Soren and aim him at the Concord Engine), Khall allies, **Maelgorn/Obsidian Synod** (Ch16).
- **E · The Cage:** sword-vessel (Ch3) → operatives-as-vessels (Ch7) → living archives as the Concord Engine's lattice (Ch9) → war-as-product + Concord Engine destroyed, dead freed (Ch16).
